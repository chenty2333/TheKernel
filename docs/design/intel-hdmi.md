# Intel HDMI packet path

`crates/ax/tk-intel-display/src/hdmi.rs` translates two MIT `intel_hdmi.c` packet operations for the HSW/display-12/13 transcoder aperture: `intel_write_infoframe()`'s reserved/ECC hole insertion and `hsw_write_infoframe()`'s enable-clear, full 32-byte data writes, re-enable, and posting read. `gcp_default_phase_possible()`/`intel_hdmi_compute_gcp_infoframe()` calculate deep-color GCP phase, and `hsw_set_infoframes()` keeps the HSW GCP, AVI, SPD, vendor, DRM ordering. The typed readout path in the same module handles AVI/SPD/vendor/DRM status and GCP readback.

Infoframe construction from connector/EDID/atomic state, AVI/SPD/vendor/HDR compute and validation, GCP compute/write, fastset updates, HDMI scrambling/SCDC, dual-mode adapters, HDCP, CEC, LSPCON, audio policy, and other platform DIP engines remain untranslated or delegated to their owning workstreams. Packet writes require the caller to own powered pipe and output sequencing; this helper refuses unless the pipe is already powered.
