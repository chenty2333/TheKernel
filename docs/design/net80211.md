# net80211 station path

The new `tk-net80211` crate starts with the station-mode Ethernet/802.11 data boundary. `ieee80211_encap()`'s STA/ToDS branch from OpenBSD `ieee80211_output.c` and `ieee80211_decap()`'s address-direction and LLC/SNAP mapping from `ieee80211_input.c` are represented as allocation-owned byte frames; the crate does not depend on mbuf/ifnet. Four-address and QoS header parsing is retained on RX so the decapsulator does not assume a fixed 24-byte header.

RSN/WPA cipher and AKM suite negotiation information is parsed from association IEs; the standard WPA four-way handshake is assigned to userspace `wpa_supplicant` via nl80211; this crate does not implement PAE or cryptography. The remaining OpenBSD station state machine, BSS/node table, probe/association frame generation, rate adaptation, regulatory data, crypto/PAE, fragment and block-ack processing are not yet translated. TX currently supports the STA ToDS non-QoS path; the iwx command/ring/firmware driver is still under implementation.
