# i915 PCode mailbox source translation

`crates/ax/tk-intel-display/src/intel_pcode_full.rs` translates all 14 ctags functions, in source order, from Linux 7.2.3 `drivers/gpu/drm/i915/intel_pcode.c` (MIT; Copyright © 2013-2021 Intel Corporation), plus the public interface in `intel_pcode.h` and all 93 definitions from `include/drm/intel/intel_pcode_regs.h`. The API preserves GEN6/GEN7 mailbox status translation, busy/timeout handling, `wait_for` retry, the 50 ms atomic fallback, preemption ordering, dGFX init handshake, runtime-PM wrapper calls, and parameter mailbox formatting. The `%ps` return-address suffix is omitted because Rust has no portable equivalent; structured diagnostics retain mailbox/value/errno. The complete grant is retained in `LICENSES/Intel-i915-PCode-MIT.txt`.

`IntelPcodeBackend` requires real MMIO, serialization/lockdep, wait and timeout, preemption, runtime-PM, and diagnostic operations; no default-success behavior is supplied. `kernel/src/drm/intel/regs/pcode.rs` adds the typed mailbox/data register offsets. `kernel/src/drm/intel/pcode.rs` implements the N305 `IntelPcodeBackend` over typed mailbox registers; `power::bring_up` now uses it for the initial unusable-CDCLK prepare/voltage handshake. The same backend now reads display memory-latency and SAGV block-time mailboxes for the N305 primary-plane WM path. Runtime atomic CDCLK transitions and a generic PCI runtime-PM owner remain unconnected.
