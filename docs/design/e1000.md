# Intel e1000 family port

The numeric register and bit definitions from FreeBSD `sys/dev/e1000/e1000_regs.h`
and `e1000_defines.h` are translated in `tk-axdriver-net::e1000::registers`
under the Intel BSD-3-Clause grant. The queue-index register offset functions
cover the documented first/fourth queue banks. Driver code in `e1000_*.c` and
`if_em.c` is not yet translated or bound to `NetDriverOps`; the PCI probe, ring
initialization, link setup, interrupt/polling flow, and QEMU coverage remain.
