# TheKernel Route

TheKernel 的高层路线由以下四个方向组成。

1. 采用新颖、先进且能够取得实际收益的方法提升 TheKernel 性能。在可复现的条件下对齐 Linux，并在合适的子系统和工作负载上超过 Linux。
2. 继续对齐 Linux ABI，实现更多 syscall 及其完整的 Linux 可见语义，最终形成完整、可发布、可用于生产的内核。
3. 继续推动组件化。在获得性能和兼容性的同时，使内核及其组件更加可验证、可靠、可维护、可移植，并能够被清晰拆解和独立理解。
4. 只支持 x86_64，并将平台启动、Linux ABI、性能优化、完整系统验证和发布工作全部集中到 x86_64。AArch64、RISC-V64 与 LoongArch 全部取消支持，相关路径可直接删除，也不再约束新接口或组件设计。

平台参考组合为：以 QEMU `q35` + UEFI/OVMF 作为 x86_64 虚拟平台，以现有的主流 Ryzen/Intel 台式机作为真实硬件。后续功能、性能和发布验收均以 x86_64 为准。

## 执行姿态

这是没有生产用户和外部兼容承诺的个人项目。为了获得明确的性能、语义、可靠性、可验证性、维护性或移植性收益，可以随时破坏和重做 TheKernel 自身的 API/ABI、crate 边界、仓库结构与实现。过时路径直接删除，不建立弃用期、兼容层、迁移流程或没有实际消费者的维护负担。
