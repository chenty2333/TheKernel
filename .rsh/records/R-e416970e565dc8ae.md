# Conclusion

Linux-visible behavior is the comparison oracle for the preview gate.

# Evidence

At TheKernel commit 84464080410c076f62f9496b86fa22f8a2ac05be, tests/guest/system-init.c `run_suite_case`, lines 571–622, maps direct child status 0/1/4 to the suite protocol and forwards diagnostics without treating them as verdicts; the suite list at lines 648–676 names the Linux-facing guest checks. tests/test_thekernel_system_test.py `test_product_defaults_and_compile_time_network_match_q35_gate`, lines 28–48, binds the product defaults to q35/UEFI/SMP4/1G and checks the platform configuration.

# Boundary

This policy does not claim that the current implementation matches Linux for every ABI surface; each claimed surface still needs its own oracle and run evidence.
