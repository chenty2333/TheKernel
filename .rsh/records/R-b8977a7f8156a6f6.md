# Conclusion

The preview gate must bind its source inputs and resulting artifacts; unbound logs cannot support the delivery claim.

# Evidence

At TheKernel commit 84464080410c076f62f9496b86fa22f8a2ac05be, config/source-combination.toml lines 1–13 pins the ax and linux_abi sibling commits. scripts/ci/source_combination.py `load` and `combination_id` restrict the declared set and derive the combination identity including the TheKernel commit. tools/qemu_runner/receipt.py `source_identity`, lines 54–83, records each checkout's commit, tree, worktree_dirty, and match_declared fields; tools/qemu_runner/evidence.py `file_evidence` hashes an artifact while checking stable device, inode, size, mtime, and ctime fields.

# Boundary

These helpers define source and file identities, not a successful gate. tools/thekernel.py `system_test_cmd` passes receipt=None, so the default q35 system-test does not itself produce the cross-command gate manifest required to bind build, lint, differential, and guest results.
