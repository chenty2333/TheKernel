# Conclusion

A truthful terminal matrix has reviewed/resolved=375, implemented=358, explicit-enosys=17, partial=0, and unknown=0. The 17 explicit ENOSYS rows must be exactly the Linux native sys_ni entries; TheKernel gaps cannot be reclassified into that set.

# Evidence

Linux 6.12.103 arch/x86/entry/syscalls/syscall_64.tbl has 375 common/64 rows. tools/abi_matrix.py normalizes blank entry fields to sys_ni_syscall. The fixed native NI set is uselib, _sysctl, create_module, get_kernel_syms, query_module, nfsservctl, getpmsg, putpmsg, afs_syscall, tuxcall, security, set_thread_area, get_thread_area, lookup_dcookie, epoll_ctl_old, epoll_wait_old, and vserver.

# Boundary

This count excludes x32 and other architectures. Configuration-gated functional syscalls are not native NI rows and require a feature-witness Linux configuration rather than an ENOSYS exception.
