# Conclusion

Post-publication DMA failure must remain in explicit custody until a terminal outcome proves retirement.

# Evidence

At TheKernel commit 84464080410c076f62f9496b86fa22f8a2ac05be, kernel/src/file/io_uring.rs lines 408–529 define per-device completion ownership, explain that failed devices retain QD owners until typed reset proof, fence admission during removal/reset, and define terminal quiesced/retired/quarantined notifications. Lines 511–529 state that the upper worker, not a callback, proves which terminal event it retired.

# Boundary

This is a fail-closed design rule evidenced by source structure. It is not a proof that all device-teardown paths or hardware resets are complete.
